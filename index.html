HOW TO READ THIS REVIEW

This independent review was prepared for the FTW Batch 12 Databricks Data Engineering Bootcamp, sponsored by Accenture. It is not an official FTW Foundation or Accenture publication, endorsement, certification, or employment assessment.

The review asks one question: Can another engineer understand, run, validate, and modify the project without relying on the original authors? It does not judge a student’s ability, effort, or career potential. A capable team can lose handoff points when setup knowledge is not recorded in the repository.

The feedback names repository changes that another engineer could verify. Scores, ratings, verdicts, and technical findings are unchanged from the detailed reviews.

Scope rule. Results are shown only within each homework. No class-level summary statistics, combined assignment totals, or performance comparisons are provided.

ESSENTIAL TERMS

  • Data pipeline: steps that move source data into tables, models, and reports.
  • Data model: the design of tables and their relationships.
  • Grain: what one row represents, such as one item in one order.
  • Validation: checks for missing values, duplicates, broken relationships, or incorrect totals.
  • Runbook: exact setup and run instructions, including access, order, commands, and expected results.
  • Handoff: giving a project to someone who did not build it, with enough information to continue without guesswork.
  • Canonical path: the one official route to run when several versions or tools are present.
  • Gate / fail-fast check: a check that stops a run when it finds a serious defect instead of merely showing a warning.
  • Fact table: measurable events, such as purchased items or learning activity.
  • Dimension table: context for facts, such as products, customers, courses, or dates.
  • Reconciliation: checking that important totals still match after data moves.
  • Schema: the expected columns, data types, and structure of a dataset.
  • Source contract: the expected source files, fields, formats, and delivery rules that an ingestion process relies on.
  • Ingestion: acquiring source data and loading it reliably into the first managed layer with traceable provenance.
  • Productionization: turning working data logic into a pipeline that can be deployed, scheduled, monitored, recovered, and operated reliably.
  • Bronze / Silver / Gold: the raw landed layer, the cleaned layer, and the analysis-ready layer in a common three-layer pipeline design.
  • Provenance / lineage: where data came from and how it moved or changed through the pipeline.
  • Incremental load: a run that processes only new or changed data.
  • Idempotent run: a repeated run with the same input that does not create duplicates or change the correct result.
  • Orchestration / DAG: task order and dependencies; DAG means directed acyclic graph.
  • CI/CD: automated checks and delivery or deployment; the initials mean continuous integration and delivery.
  • DQ / GX: data quality; Great Expectations (GX) is a tool for running these checks.
  • Databricks bundle / target: deployment files and settings for an environment.
  • Catalog, Volume, and SQL Warehouse: Databricks components used to organize governed data objects, store files, and provide SQL compute, respectively.
  • Pinned commit / SHA: the exact Git commit reviewed. A SHA is the commit’s unique identifier.
  • Quarantine: a separate location for rejected data so it can be inspected without entering trusted outputs.
  • Spark / pytest / dbt / DLT: Spark is a data-processing engine; pytest is a Python testing tool; dbt builds and tests data models; Delta Live Tables (DLT) manages Databricks pipelines.

100-POINT RUBRIC

RUBRIC DIMENSION POINTS EVERYDAY QUESTION

Architecture & Data Flow 15 Can a newcomer follow where data starts, how it changes, and where it ends?

How to Run 20 Can someone set up and run the project using complete, exact instructions?

Engineering Decisions 10 Are choices, assumptions, trade-offs, alternatives, and limits explained?
Repository Organization 5 Can a newcomer find the current files and source of truth without guessing?
